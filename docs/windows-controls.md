# 键盘与鼠标控制

默认使用[针对游戏操作的触屏界面](touch-controls.md)。键鼠面板位于“菜单 → 键鼠面板”，左上角“触屏”可返回。

| 控制 | 输入行为 |
| --- | --- |
| 直触 | 手指落下为左键按下，移动为左键拖动，抬起为释放 |
| 触控板 | 手指移动只移动指针，可用另一根手指同时按键 |
| 左键 / 右键 / 中键 | 按住保持，抬起释放；可与指针和键盘同时使用 |
| 滚轮＋ / 滚轮－ | 每次按下产生 +120 / -120 的滚轮脉冲 |
| 键盘 | 展开字母、数字、修饰键、方向键、导航键和 F1–F12 |
| 说明 | 显示当前控制的简短说明 |

常用按键 Z、X、A、S、Esc、Space、Shift、Ctrl 位于左侧。原版主循环
将 Z 补作鼠标左键、X 补作右键，前提是对应鼠标状态为零。A 的按下沿
写入 +120 滚轮，S 写入 -120，同时按下时 A 优先。这些规则来自
[Windows 输入证据](windows-input-evidence.md)，没有把 WASD 推测为移动。

连接外接键盘、鼠标时，它们与屏幕控制共同写入输入状态。按键根据
物理位置转换为 DirectInput 扫描码。外接键盘和屏幕键盘使用独立来源，
松开其中一处不会松开另一处仍按住的同一按键。

鼠标坐标覆盖整个渲染视图，由场景的 4:3 内容区换算命中位置。指针位置、
相对位移、三个鼠标按钮、滚轮和 256 个扫描码在同一次采样中组成不可变
快照，再一起交给渲染线程。短按会保留到下一帧，切后台时清除未消费
输入并释放已经采样的按键，避免粘键。

本轮完成的是输入传递和现有界面的按下/保持/释放适配。具体按键在某个
场景中的功能，仍取决于该场景是否实现了相应处理；屏幕上提供按键不
代表相应原版功能已经补齐。未推测尚缺证据的相机拖动组合。

验证包括可移植输入状态测试和实际 UIKit 控件回归，覆盖按住 Shift +
鼠标右键拖动、独立释放、短按 Z、外接与屏幕按键共同保持、失焦清理。
模拟器另保留键鼠控制层的窗口显示和截图证据；真机外接设备仍需验证。
