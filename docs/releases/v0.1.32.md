# v0.1.32

Fixes iOS app background/foreground lifecycle suspension and resumption across all scenes (`DCVulkanSpriteView`, `VulkanSurface`, `LabModel`, `DCGameAudio`, `DCIntroScene`, `DCGameScene`, `DCStartupScene`, `DCConfigScene`, `DCSaveScene`, `DCEndingScene`, and `dc_vk_sprite.c`):

- **Vulkan / MoltenVK Background-Foreground Lifecycle (`DCVulkanSpriteView`, `VulkanSurface`, `dc_vk_sprite.c`)**: Immediately suspends rendering on `UIApplicationWillResignActiveNotification` / `UIApplicationDidEnterBackgroundNotification`, drains in-flight GPU work via `dc_vk_sprite_wait_idle`, preserves resident textures across background transitions, expands renderer texture capacity to `1024`, and handles `VK_ERROR_SURFACE_LOST_KHR` / transient drawable unavailability without terminating the render loop.
- **Audio Session & Scene Clock Resumption (`LabModel`, `DCGameAudio`, `DCIntroScene`, `DCStartupScene`, `DCGameScene`, `DCConfigScene`, `DCSaveScene`, `DCEndingScene`)**: Serializes `AVAudioSession` deactivation after pausing active `AVAudioPlayer` instances, reactivates playback session on foreground entry, shifts model/text animation clocks across paused intervals, and retries audio playback across transient session interruptions without raising fatal render errors.

The IPA is unsigned and requires the existing external `Documents/game/Data` resources.
