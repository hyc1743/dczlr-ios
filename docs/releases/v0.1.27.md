# v0.1.27

Fixes character facial morph playback, `.xx` serialized node visibility, outfit variant switching across all characters, virtual keyboard / camera parity, and save-screen slot selection highlight:

- Initializes facial morph eye/mouth blends to `1.0f` (`a_On_me_op` open-eye target) and advances runtime blink phases via `dc_morph_tick`, matching `0x4121b0` and `0x412560` in `target.exe`.
- Loads the serialized node render-hide byte (`matrix_offset + 108` -> node `+0x1f0`) in `dc_model_open`, preventing hidden hair variants such as Ayaka's untied long hair (`b_On_long` in `bk00_00.xx`) from overlapping default hair.
- Completes `applyOutfitVariant:` node name tables (`0x66be70` / `0x664288`) for Reiko (`a`), Ayaka (`b_Nn_sera_OBJ`), and Erika (`c_On_uwagi`), including active bra/panty meshes (`*_On_bura`, `*_On_pantu`) and skirt meshes (`*_On_skart`).
- Aligns virtual keyboard and camera controls with `target.exe`: `1`/`2`/`3` toggle map layers (`m_Nn_level1..4`, `0x47c170`), `PgUp`/`PgDn` adjust vertical camera height (`[-30, +20]`, `0x476810`), arrow keys pan relative to camera yaw (`[-50, +50]`, `0x476230`), and `Ctrl` + left-drag orbits in Scene 5/6 (`0x492854`).
- Fixes `Save_select.ema` in `DCSaveScene` to follow the selected slot row (`_row`, `0x84d07a`) rather than the page tab (`_page`, `0x84d07b`).

The IPA is unsigned and requires the existing external `Documents/game/Data` resources.
