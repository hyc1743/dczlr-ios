# v0.1.12 测试版

未签名 iOS 测试包，版本 0.1.12，构建号 13。

- 主镜头第二个目标接入原版骨骼绑定。
- 接入原版自动镜头资源和动画，按当前帧的相机节点更新画面；自动模式期间暂停手动旋转、平移和缩放。
- 再次选择自动镜头选项可关闭自动模式，并恢复当前原版 CAM 预设。
- 分开模型更新与几何绘制，保证每帧只推进一次动画；限制自动镜头的常规诊断采样，避免日志逐帧增长。
- 保留此前的人物脚下阴影修复、首场景角色菜单、音效结束后的剧情转场，以及黑边虚拟按键和虚拟鼠标。

验证范围：本地 323 项测试、原版镜头计算指令对照、Linux/macOS Vulkan 检查，以及 iPhone 16 Pro / iOS 18.5 模拟器中的主镜头两种目标、自动模式开关、按住手动键时的自动镜头行为，以及角色菜单到第 4 段脚本的回归检查。

副镜头、存读档／编辑页面、后续角色和服装操作、完整流程仍待适配。尚未验证真机自签安装，当前测试不代表已经完整还原原版。

游戏资源没有改动，已有 `Documents/game/Data` 可继续使用，无需重新复制。
