# v0.1.26

Fixes 3D scene rendering, camera initialization, model/outfit visibility, texture capacity, and scene/system transitions:

- Removes the zero-distance primary camera override in night (`_sceneType == 6`) scenes and adds 3-tier `.cam` fallback lookup in `RPP_03.pp`.
- Raises the Vulkan renderer and `DCGameScene` texture slot cap from 64/128 to 256 so high-texture map/character scenes do not drop textures.
- Fixes `DC_VK_DEPTH_AUTO_TRANSLUCENT` so meshes with non-opaque material alpha (`< 1`) but opaque textures still write depth (`DC_VK_DEPTH_WRITE`), matching `target.exe`.
- Aligns initial and outfit-variant node visibility (`applyInitialVisibility` / `applyOutfitVariant:`), glasses animation visibility, and `_sceneType == 5` auxiliary morph/animation playback (`sm0X_00.xx` / `sm0X_01.xx`) with `target.exe`.
- Restores transition fade progression, configuration persistence (`gcd.cfg`), audio pause/resume across system screens, and save/load state across intro/ending/game scenes.

The IPA is unsigned and requires the existing external `Documents/game/Data` resources.
