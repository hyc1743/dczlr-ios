# v0.1.10 测试版

这是当前移植进度的未签名 iOS 测试包，需要使用自己的 Apple 身份签名后安装。

- 28 个常驻虚拟按键全部放在左右黑边，中央保留 4:3 游戏画面。
- 支持滑动控制虚拟鼠标、左右键、滚轮和多指组合按键。
- 恢复原资源中的右侧交互图标与初始右键菜单。
- 接入主镜头目标对准和原 `.cam` 预设复位。
- 修复隐藏部件错误停止节点坐标更新的问题，并按角色阶段选择对应资源。

已通过 GitHub 构建及 iPhone 16 Pro / iOS 18.5 模拟器中的启动、键鼠输入、首个真实场景镜头动作检查。全流程、其他镜头模式、角色动作及存读档／编辑页面仍未完成，真机运行和自签安装尚未验证。

资源包未改动，已有 `Documents/game/Data` 可以继续使用，无需重新复制资源。
